FAIR Folder Curator

FAIR Folder Curatorv0.2

Turn a messy data folder into a clean, documented dataset. A data-curator agent asks what it needs, proposes a layout, and hands you a script that copies your files into it.

Load the messy folder

The app reads file names, sizes and dates, and (if you ask) the metadata headers inside files. Everything is read on this computer; no file is uploaded. Names and short header summaries go to Claude only when you press a curator button.
